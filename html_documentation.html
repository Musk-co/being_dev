Introduction

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

"HTML is the backbone of every website."

Basic HTml Structure

<!DOCTYPE html>
<html>
    <head>
        <title>Page</title>
    </head>

    <body>
        Content
    </body>
</html>

The <head> contains metadata, while the <body> contains visible content.
